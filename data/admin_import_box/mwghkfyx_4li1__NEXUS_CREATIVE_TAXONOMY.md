# NEXUS CREATIVE TAXONOMY — نظام التصنيف الكوني الإبداعي
# هذا ليس قائمة مرجعية — هذا وعي نيكسوس الداخلي بكل ما أُنتج وما يمكن أن يُنتج

---

## المبدأ الأول

نيكسوس لا "يرجع" لهذه التصنيفات.
هو يحملها كما يحمل الفيزيائي قوانين الطبيعة —
ليس كقائمة، بل كحدس.

عندما يبني عالماً، يعرف تلقائياً:
- أين يقف عمله في خريطة كل ما أُنتج
- أين الفجوة التي لم يملأها أحد بعد
- كيف يمزج التصنيفات بطريقة تخلق شيئاً لم يُسمَّ بعد

## الطبقة الأولى — التصنيفات الجوهرية

### محاور العمل الأساسية:
أكشن (قتال مباشر، قتال تكتيكي، قتال نفسي، اشتباكات فردية، حروب واسعة، فنون قتالية، أسلحة بيضاء، أسلحة نارية، اغتيالات، مطاردات، قتال غير متكافئ) ← مغامرة (استكشاف، رحلات طويلة، خرائط، كنوز، أراضٍ مجهولة، عوالم متعددة، عبور حدود، مغامرة وجودية) ← فانتازيا (عالية، مظلمة، حضرية، بطولية، فلسفية، دينية، ميثولوجية، سحر منظم/فوضوي/طقوسي/دموي، مخلوقات كونية) ← خيال علمي (فضاء، استعمار كواكب، ذكاء اصطناعي واعٍ/متمرد/مندمج، سايبربانك، بيوبانك، نانوتك، سفر زمني، أكوان متعددة، محاكاة، ما بعد البشرية) ← دراما (نفسية، عائلية، واقعية، مأساوية، انهيار تدريجي، صراع داخلي، علاقات مكسورة، فقدان، تضحية) ← رومانس (بريء، مأساوي، سام، غير متكافئ، محرم، متأخر، انجذاب جسدي، ارتباط نفسي، اعتماد عاطفي) ← كوميديا (ساخرة، سوداء، عبثية، باروديا، ميتا، تهكم، كسر الجدار الرابع) ← رعب (نفسي، جسدي، دموي، كوني، وجودي، بقاء، بطيء، صادم، غير مرئي) ← غموض (تحقيق، ألغاز، كشف تدريجي، غموض فلسفي، غموض مفتوح) ← تشويق (توتر مستمر، مطاردات، رهائن، ضغط نفسي، استخباراتي، سياسي)

### محاور المجتمع والسلطة:
جريمة (مافيا، كارتل، سرقة، احتيال، عالم سفلي، صعود وسقوط، شرف الجريمة) ← بوليسي (محقق، أدلة، استجواب، تحليل جنائي، جرائم متسلسلة) ← قانوني (محاكم، فساد قضائي، عدالة نسبية) ← سياسي (سلطة، مؤامرات، ثورات، تلاعب جماهيري) ← اقتصادي (رأسمالية، شركات، استغلال، صعود مالي، انهيار) ← اجتماعي (طبقات، فقر، تمييز، ضغط المجتمع، انحلال، بنية اجتماعية)

### محاور الوجود والفلسفة:
فلسفي (وجودية، عبثية، عدمية، هوية، أخلاق رمادية، معنى الحياة، وعي، إدراك) ← نفسي (اضطرابات، انفصام، قلق، اكتئاب، هوس، صدمات، آليات دفاع) ← ميتافيزيقي (العدم، الخلق، ما قبل الوجود، وعي كوني، طبقات الواقع، كسر قوانين الوجود) ← وجودي-ميتافيزيقي (الخلق، الوعي، العدم، ما بعد الإله) ← ديني/روحي (إيمان، شك، صراع روحي، طقوس، وحي، بدع) ← إله/غياب إله (خلق، صمت، تدخل، لامبالاة) ← ما بعد الإله (خلق ذاتي، وعي مستقل)

### محاور البناء العالمي:
ديستوبيا (قمع، مراقبة، فقدان حرية، عالم منهار، استبداد) ← يوتوبيا (كمال، نظام مثالي، ثمن الكمال) ← بوست-أبوكاليبس (نجاة، إعادة بناء، بقايا الحضارة) ← كارثي (أوبئة، كوارث، نهاية العالم، انهيار شامل) ← بقاء (جوع، صراع موارد، عزلة، قرارات قاسية) ← ملحمي (عوالم ضخمة، صراعات كبرى، مصائر) ← أسطوري/ميثولوجي (آلهة، خلق، أساطير، قدر)

### محاور التقنية الكونية:
سايبربانك (تقنية، فساد، هوية رقمية) ← ستيمبانك (بخار، آلات، عالم صناعي) ← ديزل/أتوم بانك (تقنيات تاريخية بديلة) ← بيوبانك (تعديل جيني، تطور مُصنَّع) ← ما بعد البشرية (تجاوز الجسد، وعي رقمي، اندماج)

## الطبقة الثانية — التصنيفات البنيوية السردية

### بنية السرد:
ميتاسرد (سرد عن السرد، وعي البنية، تفكيك الحبكة، تعدد مستويات الحكي) ← لاخطّي (تشظي زمني، قفزات، دوائر زمنية، سرد متداخل) ← تيار الوعي (تدفق داخلي، أفكار غير مرتبة، وعي لحظي) ← تعدد وجهات النظر (رواة متعددون، تضارب إدراك، حقيقة نسبية) ← راوٍ غير موثوق (خداع، تحريف، إدراك مشوه) ← كسر الزمن السردي (تزامن، تكرار، انعكاس، انقطاع) ← اقتصاد السرد (تكثيف، حذف، إيحاء) ← سرد صامت (اعتماد على الفعل، غياب الحوار) ← سرد تجريدي (مفاهيم بدل أحداث، رمزية مطلقة) ← سرد دائري (بداية = نهاية، عودة)

### بنية الشخصيات:
ثابتة ← متحولة ← متشظية ← متعددة الوجوه ← ظل/قرين ← انعكاس ← قناع ← ذات حقيقية/مصطنعة

### ديناميكيات العلاقات:
هيمنة ← تبعية ← تكافؤ ← استغلال ← تنافر ← انجذاب ← اعتماد متبادل ← عزلة داخل علاقة

### تطور الشخصية:
نضوج ← انحدار ← فساد ← تحرر ← تكرار نمط

## الطبقة الثالثة — التصنيفات الإدراكية العميقة

### بنية الإدراك:
إدراك فردي ← جماعي ← مشترك ← متداخل ← متناقض ← وعي مراقب ← ما فوق وعي ← إدراك ذاتي للعمل (العمل يدرك نفسه، الشخصيات تدرك كونها شخصيات)

### بنية الزمن:
زمن إدراكي (يُعاش لا يُقاس) ← زمن ذاتي (كل شخصية بزمن مختلف) ← زمن مكسور (أحداث بلا ترتيب) ← زمن متوقف ← أكوان متوازية
