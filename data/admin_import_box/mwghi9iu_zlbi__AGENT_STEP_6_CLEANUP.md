# الخطوة 6 — التنظيف النهائي

نفّذ هذه الخطوة فقط بعد نجاح **كل** فحوصات الخطوة 5 بلا استثناء.

## 1. احذف النسخة الاحتياطية المؤقتة

```bash
rm server/gemini.backup.ts
```

هذا آمن الآن لأن كل الفحوصات نجحت وأثبتت أن التعديل سليم.

## 2. احذف ملفات الاختبار القديمة غير المستخدمة

هذه الملفات تحتوي مفاتيح API بنص صريح ولا قيمة وظيفية حالية لها في المشروع:

```bash
rm -f test_or_genimage.ts test_or_claude3.ts test_or2.ts test_or_img.ts test_or_image_gen.ts test_or_vision.ts test_or_img2.ts test_or_claude2.ts
```

إذا لم توجد هذه الملفات في مسار المشروع الجذر، تحقق أولاً بـ:

```bash
find . -maxdepth 1 -iname "test_or*"
```

واحذف فقط ما هو موجود فعلياً — لا تفترض المسار.

## 3. تقرير الإنجاز النهائي المطلوب منك

بعد إتمام كل شيء، قدّم تقريراً يتضمن بالضبط:

- تأكيد أن كل فحوصات الخطوة 5 نجحت (اذكر كل فحص ونتيجته الفعلية)
- عدد أسطر `server/gemini.ts` قبل وبعد التعديل
- قائمة الملفات التي حُذفت فعلياً
- أي ملاحظة أو شك متبقٍ لم تحسمه بثقة كاملة

لا تكتب "تم بنجاح" بدون إرفاق نتائج الفحوصات الفعلية معه.
