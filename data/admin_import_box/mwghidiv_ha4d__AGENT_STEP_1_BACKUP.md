# الخطوة 1 — النسخ الاحتياطي الإلزامي

## ماذا تفعل بالضبط

قبل أي تعديل، نفّذ:

```bash
cp server/gemini.ts server/gemini.backup.ts
```

## لماذا هذه الخطوة إلزامية

إذا حدث خطأ في أي خطوة لاحقة، يجب أن يكون بإمكانك المقارنة الفعلية بين النسخة الأصلية والمعدَّلة — لا الاعتماد على الذاكرة أو الافتراض.

## التحقق

```bash
ls -la server/gemini.ts server/gemini.backup.ts
```

يجب أن يظهر الملفان بنفس الحجم بالضبط في هذه اللحظة (لأنك لم تُعدّل شيئاً بعد).

## ملاحظة مهمة

هذا الملف `gemini.backup.ts` **يُحذف في الخطوة الأخيرة (6)** بعد التأكد من نجاح كل شيء — لا تتركه في المشروع بشكل دائم. الاحتفاظ به مؤقتاً فقط لغرض المقارنة أثناء هذه المهمة.
