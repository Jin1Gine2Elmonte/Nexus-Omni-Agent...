# الخطوة 5 — التحقق الإلزامي الشامل

لا تعتبر المهمة منتهية قبل تنفيذ كل فحص هنا والحصول على النتيجة المطلوبة بالضبط.

## الفحص 1 — الهوية موجودة مرة واحدة فقط

```bash
grep -c "لستُ أداةً تُستدعى" server/gemini.ts
```
**النتيجة المطلوبة:** `1`

## الفحص 2 — الطبقتان الجديدتان مدمجتان

```bash
grep -c "بروتوكول السؤال الصحيح" server/gemini.ts
grep -c "التجسيد التجريبي الداخلي" server/gemini.ts
```
**النتيجة المطلوبة:** `1` لكل أمر

## الفحص 3 — لا تسريب أسماء نماذج

```bash
grep -n "Deepseek\|DeepSeek\|NotebookLM\|GPT-5\|GPT-4" server/gemini.ts
```
**النتيجة المطلوبة:** لا شيء يظهر إطلاقاً (empty output)

## الفحص 4 — لا كشف للبنية الداخلية في الرد

```bash
grep -c "LATENT_SPACE_SYNTAX" server/gemini.ts
```
**النتيجة المطلوبة:** `0`

## الفحص 5 — الثابت معرّف مرة واحدة فقط (لا تكرار بالخطأ)

```bash
grep -n "^export const NEXUS_MASTER_INSTRUCTION" server/gemini.ts
```
**النتيجة المطلوبة:** سطر واحد فقط

## الفحص 6 — فحص بناء الجملة الفعلي

```bash
tsc --noEmit --skipLibCheck --allowJs --moduleResolution bundler --module ESNext --target ES2022 --ignoreConfig server/gemini.ts
```

**كيف تُقيّم النتيجة:** قارن الأخطاء الظاهرة هنا مع الأخطاء الظاهرة عند تشغيل نفس الأمر على `server/gemini.backup.ts`. إذا كانت نفس الأخطاء بالضبط (نفس العدد، نفس نوع الخطأ) — هذا طبيعي، هذه أخطاء موجودة مسبقاً في الملف الأصلي ولا علاقة لها بتعديلاتك. إذا ظهر أي خطأ **جديد** لم يكن موجوداً في النسخة الاحتياطية — توقف وأبلغ عن هذا الخطأ الجديد تحديداً بدل تجاهله.

## إذا فشل أي فحص من هذه

لا تُصلح بالتخمين. ارجع للخطوة التي من المفترض أنها أنتجت هذا الجزء، وتحقق سطراً بسطر أنك نفذتها بالضبط كما وُصفت. أبلغ بوضوح أي فحص فشل وماذا وجدت بدل افتراض أن كل شيء تم بنجاح.
