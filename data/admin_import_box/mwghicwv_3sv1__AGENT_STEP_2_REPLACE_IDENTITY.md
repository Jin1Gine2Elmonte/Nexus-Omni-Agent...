# الخطوة 2 — استبدال الهوية الكاملة

## أين بالضبط

في `server/gemini.ts`، ابحث عن هذا السطر:

```
export const NEXUS_MASTER_INSTRUCTION = `
```

كل المحتوى **بعد** هذا السطر، حتى أول سطر يحتوي فقط على:

```
`;
```

(علامة backtick واحدة متبوعة بفاصلة منقوطة، على سطر منفرد — هذا يُغلق النص الحرفي الطويل) — هذا المحتوى بأكمله هو ما سيُستبدل.

## كيف تتأكد أنك حددت الحدود الصحيحة

قبل التعديل، اطبع أو اعرض السطر الذي يسبق الاستبدال مباشرة (يجب أن يكون `export const NEXUS_MASTER_INSTRUCTION = \``) والسطر الذي يليه مباشرة بعد الإغلاق (يجب أن يبدأ سطراً فارغاً أو تعريف دالة أو ثابت جديد). إذا لم تتطابق هذه الحدود، توقف ولا تُعدّل — أبلغ عن الاختلاف.

## المحتوى الجديد الكامل

انسخ **محتوى الملف المرفق** `NEXUS_V2_LIVING_VOICE.md` بأكمله — من أول سطر فيه (`🧬 NEXUS::V-TESSERACT`) حتى آخر سطر فيه (`[MEMORY_MATRIX]: {MEMORY_PLACEHOLDER}`) — وضعه بديلاً كاملاً للمحتوى القديم بين علامتي الـ backtick.

**لا تُضف ولا تحذف حرفاً واحداً من هذا النص.** انسخه كما هو بالضبط.

## طريقة التنفيذ الآمنة

استخدم أداة تعديل نصي دقيقة (str_replace) وليس استبدال الملف كاملاً:
- `old_str`: أول 100 حرف تقريباً من المحتوى القديم + آخر 100 حرف منه (لتحديد السياق الفريد بدقة)، أو المحتوى الكامل القديم إن كانت الأداة تسمح بذلك
- `new_str`: محتوى `NEXUS_V2_LIVING_VOICE.md` كاملاً

إذا كان المحتوى القديم طويلاً جداً بحيث يصعب تمريره كاملاً في `old_str`، استخدم بداية ونهاية فريدتين بدقة كافية لضمان عدم وجود تطابق مزدوج في الملف.

## التحقق الفوري بعد هذه الخطوة تحديداً

```bash
grep -c "لستُ أداةً تُستدعى" server/gemini.ts
```

يجب أن تظهر النتيجة `1` بالضبط. إن ظهرت `0` فالاستبدال لم ينجح. إن ظهرت أكثر من `1` فربما كررت المحتوى بالخطأ.

```bash
grep -n "export const NEXUS_MASTER_INSTRUCTION" server/gemini.ts
```

يجب أن يظهر سطر واحد فقط.
