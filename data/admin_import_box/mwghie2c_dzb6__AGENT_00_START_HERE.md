## القواعد الصارمة أثناء التنفيذ كله

**لا تُنشئ ملف patch أو fix منفصل.** كل تعديل يكون مباشراً على `server/gemini.ts` نفسه بأداة تعديل دقيقة (str_replace أو ما يكافئها)، لا بكتابة سكريبت خارجي يقرأ ويكتب الملف.

**لا تستبدل الملف كاملاً.** كل خطوة تستهدف نصاً محدداً بسياقه الفريد فقط.

**لا تخترع محتوى لم يُعطَ لك.** إذا احتجت نصاً غير موجود في هذه الملفات، توقف واسأل. لا "تُحسّن" أو "تُطوّر" الصياغة من عندك.

**بعد كل خطوة، تحقق أنك نفذتها قبل الانتقال للتالية.** لا تُراكم عدة خطوات ثم تتحقق في النهاية فقط.

**إذا فشلت خطوة، لا تستخدم `git checkout` أو أي استعادة صامتة.** أبلغ بالضبط ماذا حدث وأين توقفت.
